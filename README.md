# X Desktop 🚀
**تطبيق سطح المكتب المستقل لمنصة X (تويتر) لنظام لينكس**

تطبيق مكتبي رسمي ومستقل لمنصة X مبني بإطار عمل Electron لنظام Linux (مع دعم أصيل وشامل لـ Wayland و Niri و Hyprland)، بنفس معمارية وتكامل تطبيقي `spotify-desktop` و `netflix-desktop`. يوفر عزلاً تاماً للجلسة والبيانات عن متصفحك اليومي، مع الاحتفاظ بواجهة X الأصلية الكاملة، ومزوداً بحاجب إعلانات شبكي ومحرك ترجمة فورية دقيقة إلى اللغة العربية.

---

## ✨ المميزات الرئيسية (Key Features)

- **🌐 ترجمة فورية دقيقة إلى اللغة العربية (Free & Accurate In-Place Translation):**
  - زر أنيق `🌐 ترجمة إلى العربية` يظهر تلقائياً أسفل التغريدات الأجنبية في التايم لاين.
  - ترجمة فائقة السرعة مع كاش ذكي بالذاكرة، وإمكانية إخفاء وإظهار النص الأصلي بضغطة زر.
  - إمكانية تظليل أي نص والضغط كليك يمين لاختيار `🌐 ترجمة النص إلى العربية` ليظهر في إشعار منبثق فوري.
- **🛡️ حاجب إعلانات شامل ونظيف (Network & DOM Ad-Blocker):**
  - حظر التغريدات الممولة (Promoted Tweets) ومؤشرات الإعلانات المزعجة في التايم لاين.
  - حظر خوادم وشبكات التتبع والتحليلات الإعلانية على مستوى الشبكة (`ads-api.twitter.com`, `analytics.x.com`).
  - إخفاء بنرات وصناديق "Subscribe to Premium" الترويجية في الشريط الجانبي.
- **🔍 تكبير وتصغير متطور (Full Zoom Control):**
  - `Ctrl + سكرول بالماوس للأمام / للخلف` للتكبير والتصغير السلس.
  - `Ctrl + =` (الزر المجاور لـ Backspace مباشرة بدون Shift) للتكبير، و `Ctrl + -` للتصغير، و `Ctrl + 0` للضبط على 100%.
- **🔗 توجيه الروابط الخارجية للمتصفح الافتراضي:**
  - جميع الروابط الخارجية وروابط `t.co` تفتح تلقائياً في متصفحك اليومي (Brave) في تبويب جديد دون أن يغادر التطبيق التايم لاين.
- **🎵 تكامل أزرار الوسائط MPRIS (D-Bus):**
  - تحكم كامل بالفيديوهات والمساحات الصوتية (Spaces) عبر أزرار الكيبورد وشريط المهام (Waybar / Caelestia) عبر `playerctl`.
- **🖼️ تكامل العتاد والواجهة (Wayland, Niri & Hyprland):**
  - دعم أصيل لـ Wayland مع قواعد نوافذ رسمية لـ Niri و Hyprland.
  - أيقونة شريط النظام (System Tray) مع قائمة سريعة ودعم التصغير للـ Tray.

## 🛠️ التثبيت والتشغيل (Installation & Setup)

### التثبيت المكتبي السريع:
```bash
cd /home/omar/Projects/x-desktop
make install
```

### التشغيل:
```bash
x-desktop
```
أو ابحث عن **X** في مشغل التطبيقات (Fuzzel أو Rofi).

## ⌨️ اختصارات لوحة المفاتيح والماوس (Shortcuts)

| الاختصار | الوظيفة |
| :--- | :--- |
| `Ctrl + Wheel Up / Down` | تكبير / تصغير محتوى الصفحة بسكرول الماوس |
| `Ctrl + =` | تكبير الصفحة (Zoom In) بدون Shift |
| `Ctrl + -` | تصغير الصفحة (Zoom Out) |
| `Ctrl + 0` | إعادة ضبط حجم العرض الافتراضي 100% |
| `Ctrl + 1 .. 5` | الانتقال السريع: الرئيسية، الاستكشاف، الإشعارات، الرسائل، المحفوظات |
| `Ctrl + N` | فتح نافذة كتابة منشور جديد (Compose Tweet) |
| `Ctrl + Shift + P` | تشغيل / إغلاق وضع الصورة في صورة (PiP) للفيديو |
| `Ctrl + Shift + I` | فتح أدوات المطورين (DevTools) |
