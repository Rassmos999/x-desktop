# X Desktop 🚀
**تطبيق سطح المكتب المستقل لمنصة X (تويتر) لنظام لينكس**

تطبيق مكتبي رسمي ومستقل لمنصة X مبني بإطار عمل Electron لنظام Linux (مع دعم أصيل وشامل لـ Wayland و Niri و Hyprland)، بنفس معمارية وتكامل تطبيقي `spotify-desktop` و `netflix-desktop`. يوفر عزلاً تاماً للجلسة والبيانات عن متصفحك اليومي، مع الاحتفاظ بواجهة X الأصلية الكاملة، ومزوداً بتطويرات عملية متقدمة لتحسين تجربة الاستخدام.

---

## ✨ المميزات الرئيسية (Key Features)

- **عزل تام للجلسة والملف الشخصي:** حفظ ملفات الجلسة والكوكيز في `~/.config/x-desktop/` دون أي مشاركة أو تعارض مع Brave أو Chrome أو Firefox.
- **واجهة X الأصلية بنسبة 100%:** استخدام الواجهة الرسمية الأصلية مع تنقية بنرات الويب الترويجية وإعلانات "تثبيت التطبيق".
- **تكامل أزرار الوسائط MPRIS (D-Bus):** تحكم كامل بالفيديوهات والمساحات الصوتية (Spaces) عبر أزرار الكيبورد المباشرة أو عبر شريط المهام (Waybar / Caelestia) باستخدام `playerctl`.
- **نافذة عائمة للفيديو (Picture-in-Picture - PiP):** زر مدمج على مشغل الفيديو في أي تغريدة يتيح تشغيل الفيديو في نافذة عائمة دائرية الزوايا مع تثبيتها في ركن الشاشة (مع اختصار `Ctrl+Shift+P`).
- **زر تحميل الوسائط المباشر:** زر تحميل أنيق مدمج في شريط إجراءات التغريدة لتحميل الصور بأعلى دقة أصلية (orig) والفيديوهات مباشرة إلى مجلد `~/Downloads`.
- **تكامل Wayland و Niri و Hyprland:** دعم `--ozone-platform-hint=auto` وتسريع العتاد (VA-API) مع قواعد نوافذ جاهزة لمديري النوافذ المتجانبة.
- **أيقونة شريط النظام (System Tray):** تدعم التصغير لشريط النظام، مع قائمة سريعة لفتح الرسائل، الإشعارات، أو كتابة منشور جديد فورياً (`Ctrl+N`).

## 🛠️ التثبيت والتشغيل (Installation & Setup)

### التثبيت المكتبي السريع:
```bash
cd /home/omar/Projects/x-desktop
make install
```
سيتم تثبيت التطبيق في:
- المشغل: `~/.local/bin/x-desktop`
- ملف التشغيل: `~/.local/share/applications/x-desktop.desktop`
- الأيقونات: `~/.local/share/icons/hicolor/.../apps/x-desktop.png`

### التشغيل:
```bash
x-desktop
```
أو ابحث عن **X** في مشغل التطبيقات (Fuzzel أو Rofi).

## 📦 حزم التوزيع (Packaging)

- **بناء حزمة Arch Linux (.pkg.tar.zst):**
  ```bash
  make package-arch
  ```
- **بناء حزمة Debian / Ubuntu (.deb):**
  ```bash
  make package-deb
  ```
- **بناء حزمة Fedora / RHEL (.tar.gz / .rpm):**
  ```bash
  make package-rpm
  ```
- **بناء جميع الحزم دفعة واحدة:**
  ```bash
  make package
  ```

## ⌨️ اختصارات لوحة المفاتيح (Shortcuts)

| الاختصار | الوظيفة |
| :--- | :--- |
| `Ctrl + N` | فتح نافذة كتابة منشور جديد (Compose Tweet) |
| `Ctrl + Shift + P` | تفعيل / إلغاء وضع الصورة في صورة (PiP) للفيديو الحالي |
| `Ctrl + R` | تحديث الصفحة |
| `Alt + Left` | الرجوع للصفحة السابقة |
| `Alt + Right` | التقدم للأمام |
